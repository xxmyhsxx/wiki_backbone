# LLM Wiki 通用模板

## LLM Wiki 介绍

LLM Wiki 是一种利用大语言模型构建和持续维护知识库的方式。用户选择资料、明确方向并提出问题；LLM 将资料整理成相互链接的 Markdown 页面，并随着新资料和讨论更新已有内容。这份介绍参考 [Karpathy 的 LLM Wiki 原始说明](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)。

它的核心是把资料整理的结果保存为可反复使用的知识页面。每次阅读和探索都可以补充概念、方法、比较与结论，建立相关页面之间的联系，让之后的阅读和提问复用已有工作。

本模板采用三个相互配合的部分：

- **来源资料：** `raw/` 保存原始资料及忠实副本，供整理和核对时回查。
- **知识页面：** `wiki/` 保存经过理解和组织的知识，用页面链接和索引连接相关内容。
- **工作约定：** `AGENTS.md`、资料与页面规范以及 Skills，说明 Agent 应如何组织内容、处理任务和维护 Wiki。

日常工作通常包括三个环节：

- **资料入库：** 阅读新来源，将有价值的内容整合到知识页面，更新相关解释和链接。
- **围绕 Wiki 提问：** 根据已有页面及其来源回答问题，将值得保留的分析继续整理进 Wiki。
- **持续维护：** 检查相互矛盾或过时的结论、缺失的链接和知识空白，确定需要修订或继续研究的内容。

用户负责选择来源、确定重点和复核重要结论，LLM Agent 协助整理与维护。本项目使用本地 Markdown 文件保存内容，使用 Git 提交记录版本；知识页面保留来源与适用条件，便于阅读和核对。

## 项目使用

本项目的目的是帮助一个用户完成 LLM Wiki 的初始化。项目提供通用文件与目录模板，并通过 `wiki-init` Skill 将模板定制为用户自己的 Wiki。初始化先确定用途、范围和工作约定，为之后的资料整理与知识维护提供起点。

### 1. 获取模板

当前模板以本地 Git 仓库提供。将下面的 `/path/to/wiki_backbone` 替换为模板仓库的实际路径：

```bash
git clone /path/to/wiki_backbone my-wiki
cd my-wiki
```

模板发布到远程仓库后，可将本地路径替换为远程仓库地址。

### 2. 使用 wiki-init

在自己的模板副本中打开 Agent，让它使用 [wiki-init](.agents/skills/wiki-init/SKILL.md)。说明用途、主题和已有资料；如需初始化到其他目录，同时提供目标位置。

可以这样开始：

```text
请使用 .agents/skills/wiki-init/SKILL.md 初始化当前 Wiki。
我希望用它整理……，主要用于……。
我已有的资料是……。
请先和我讨论定位、范围和目录安排，再完成已确定的方案。
```

没有初始资料时，也可以先完成目录与工作约定的初始化。

### 3. 确定方案并完成初始化

Agent 会结合你的需求讨论定位、范围和目录安排，再完成已确定的方案：

- 定制 README、AGENTS、来源资料说明和知识页面规范。
- 在 `wiki/SELF.md` 中记录用途、范围、实际已有内容和下一步。
- 调整必要目录，建立指向实际文件的导航，并检查链接与说明是否一致。

完成后，查看 README、SELF 和 INDEX，确认 Wiki 的目的、组织方式和使用入口符合你的需求。

### 目录与文件

```text
.
├── README.md                  项目介绍与使用入口
├── AGENTS.md                  Agent 工作约定
├── .gitignore                 本地文件忽略规则
├── raw/
│   └── README.md              来源资料的保存规则
├── wiki/
│   ├── README.md              知识页面规范
│   ├── SELF.md                Wiki 定位、范围与当前画像
│   └── INDEX.md               知识导航
└── .agents/
    └── skills/
        └── wiki-init/
            └── SKILL.md       初始化方法
```

`raw/` 保存可追溯的来源，`wiki/` 组织经过理解的知识。具体分类由用户需求决定，有实际内容时再建立相应目录。

### 初始化后的入口

- 查看定位和当前状态：[wiki/SELF.md](wiki/SELF.md)。
- 浏览知识：[wiki/INDEX.md](wiki/INDEX.md)。
- 保存来源资料：[raw/README.md](raw/README.md)。
- 编写与维护知识页面：[wiki/README.md](wiki/README.md)。
- 了解 Agent 的工作约定：[AGENTS.md](AGENTS.md)。

初始化后，本文件应介绍用户自己的 Wiki；定位、范围和当前画像由 `wiki/SELF.md` 持续维护。
