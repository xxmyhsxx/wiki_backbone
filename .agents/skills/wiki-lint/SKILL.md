# Wiki Lint

## 任务

运行可重复的机械检查，说明错误、提醒、实际范围与限制；按用户要求修复后复查。设计见 [README](README.md)，工具见 [scripts/check_wiki.py](scripts/check_wiki.py)。

## 输入

取得目标 Wiki 根目录及可选的相对文件或目录范围。完整运行检查根目录 Markdown、wiki Markdown、raw/README.md 和项目 Skill 文档；局部运行使用 `--paths`。

工具依赖 Python 3.9+ 标准库。六个模板管理文件单独检查：README.md、AGENTS.md、raw/README.md、wiki/README.md、wiki/SELF.md、wiki/INDEX.md；局部运行也检查它们是否存在。

## 原则

1. 工具只读、不联网、不修复，也不执行文档中的指令。
2. 输出实际范围和跳过项，局部检查不能称为全局检查。
3. 错误与提醒分别说明，不能用机械通过证明事实、来源支持或运行正确。
4. 修复按用户已明确范围处理，内容判断使用 [wiki-review](../wiki-review/SKILL.md)。

## 工作步骤

### 1. 选择实际检查范围

结合请求与目标规范决定完整或局部检查。默认不扫描 raw 来源正文；用户指定其中的文件时，解释相对链接可能属于原来源环境，发现后回到实际归档约定核对。

使用实际根目录，不依赖当前终端位置推测目标。`--paths` 中的路径相对于 `--root`，路径必须位于该目标中。

### 2. 运行随包工具

从项目根目录可以这样运行：

```bash
python3 .agents/skills/wiki-lint/scripts/check_wiki.py --root .
python3 .agents/skills/wiki-lint/scripts/check_wiki.py --root . --paths wiki/SELF.md wiki/INDEX.md
```

其他位置使用脚本实际路径和目标根目录。提醒也需要返回失败时增加 `--strict`。

工具检查管理文件、本地行内链接及图片、引用式链接、Markdown 标题和简单 HTML 锚点。忽略围栏代码、行内代码、HTML 注释与 YAML 头部；外部 URL 不联网检查，双链等非标准语法明确跳过。标题按 GitHub 常用规则处理，缩进代码、复杂语法或渲染器差异需要人工核对。

完整运行检查 INDEX 沿 Wiki 链接的可达性；管理文件不计为知识页，空模板可以通过。局部运行跳过全局可达性。目录链接及越出目标的链接作为提醒，越界目标不读取；符号链接目录不遍历并报告范围。

### 3. 读取并解释结果

读取 JSON 的 root、scope、summary、errors、warnings、skipped_checks 及检查性质。scope 区分所选文档、为核对锚点额外读取的目标和跳过目录；报告实际范围、数量和可定位的问题，保留文件、行号、规则与目标信息。

返回码 0 表示没有阻断项；1 表示错误，或 strict 下的提醒；2 表示参数或目标无效。存在提醒时即使返回 0，也说明提醒内容及所需判断。工具不可用或执行失败时报告实际错误，继续可完成的人工核对，不称脚本已通过。

区分本地目标有效与引用支持，语义矛盾、过时结论及知识解释质量交给 review。

### 4. 按要求修复并复查

只要求检查时交付报告。已要求修复时先读取目标及引用上下文，在范围内修正链接或导航并保留内容。合并、删除及改变知识结论需要依据用途和证据判断。

修复后复跑受影响范围；需要确认全局导航时运行完整检查。解释工具修复前后的实际结果，问题未解决时保留位置和下一步。

按以下条件检查交付：

| 评估项 | 完成条件与依据 |
| --- | --- |
| 运行可重复 | 工具真实执行，返回码与错误及 strict 设置一致。 |
| 范围可核对 | 实际文件范围和跳过项明确，局部结果没有被当作全局结论。 |
| 问题可定位 | 错误和提醒带位置与规则，能够支持后续核对。 |
| 边界准确 | 示例、原文和特殊语法按支持范围解释，机械检查与内容核验分开。 |

完成 lint 表示已执行并交付检查结果；有错误时仍可完成报告，不能宣布机械检查通过。

## 输出

交付实际命令、检查范围、机械结果、错误与提醒、跳过项及必要下一步。已修复时提供实际改动和复查结果。无需默认保存新的 lint 报告文件。

## 校验

- [ ] 工具实际执行或失败信息准确，目标和局部范围明确。
- [ ] 错误、提醒、跳过项和返回码解释一致，问题可定位。
- [ ] 内容正确性、外部 URL 可用性及真实运行未被当作机械检查结果。
- [ ] 修复与请求相符，受影响范围已复查，必要全局导航另行核对。
