# Wiki 初始化

## 目标

基于通用模板完成用户自己的 Wiki 初始化，使用户和新进入的 Agent 能理解 Wiki 的目的、组织方式和下一步行动。

本 Skill 位于模板的 `.agents/skills/wiki-init/` 中。通用文件在同一项目根目录，定制时保留其职责分工：

- [README](../../../README.md)：项目介绍与使用入口。
- [AGENTS](../../../AGENTS.md)：Agent 工作约定。
- [SELF](../../../wiki/SELF.md)：Wiki 定位、范围、当前画像与下一步。
- [Wiki 规范](../../../wiki/README.md)：知识页面的组织、表达和维护规则。
- [raw 规范](../../../raw/README.md)：来源资料的保存与追溯规则。
- [INDEX](../../../wiki/INDEX.md)：实际知识内容的导航。

## 明确需求与位置

结合当前对话，确认目标 Wiki 目录、用户的用途与主题、内容范围及已有资料。只补问会影响初始化的缺口，不重复询问已明确的信息。

用户已在模板副本中要求初始化当前 Wiki 时，以该副本为目标。要求创建到其他位置时，明确目标目录。写入前查看目标中已有的说明、资料和知识。

## 完成初始化

1. **确定定位与组织方式。** 与用户讨论用途、范围、来源类型及必要的知识分类。保留用户明确选择；普通实现细节自主决定，重要取舍确定后在该范围内完成初始化。
2. **准备模板文件。** 在新目标中创建 README、AGENTS、`.gitignore`、raw 说明、Wiki 规范、`wiki/SELF.md`、INDEX 和本 Skill。已经具备模板文件时直接定制；已有 Wiki 则保留有效内容，补全缺失文件并调整相关约定。复制模板文件时不复制 `.git/`。
3. **定制项目说明与约定。** README 介绍用户自己的 Wiki 并提供入口；AGENTS 引用实际规范和可用 Skill；raw 与 Wiki 规范根据资料类型和组织方式调整。知识分类按需求和实际内容建立。
4. **填写 SELF。** 写明服务对象、用途、主题、内容范围、当前实际内容、主要缺口及下一步。已保存资料、已形成知识和计划中的内容分别说明。
5. **建立导航并核对。** INDEX 连接已有管理入口和实际知识页面；有内容时再组织主题与阅读路径。检查文件职责、链接与描述是否一致。

缺少初始资料时，可以完成结构与约定的初始化，SELF 如实记录尚无资料或知识。需要处理初始资料、写入知识或增加其他 Skill 时，按已明确的用户需求完成相应工作。

保留目标中已有的 Git 历史与远程配置，初始化不向模板仓库推送用户内容。用户要求配置或发布自己的仓库时，作为该用户明确提出的 Git 工作处理。

## 完成与交付

初始化完成时核对：

- README 与 SELF 能说明这个 Wiki 的目的和范围，AGENTS 能指向实际可用的规范与 Skill。
- 目录和导航对应实际文件，Markdown 相对链接可定位到目标。
- 用户原有内容得到保留，当前画像未把资料收录或计划写成已完成的知识。
- 重要的未决问题已明确记录；没有资料不影响结构与约定的初始化完成。

交付目标目录、主要定制结果、使用入口和必要的遗留问题，说明实际核对范围。格式与链接检查不代替知识内容核验。
