# Wiki Review

## 任务

依据目标用途和实际材料审核内容，交付有证据的发现及建议；按用户要求修复并核对结果。当前设计见 [README](README.md)。

## 输入

取得目标 Wiki、页面或问题、审核重点与修复范围。读取 SELF、相关规范和目标正文，从关键主张定向回查来源，复用实际来源登记方式。

审核初始化约定时采用 [wiki-init](../wiki-init/SKILL.md) 的指标；知识页面依据该 Wiki 的读者基础与质量要求。范围不明确且影响工作时补问，已经明确的范围直接使用。

## 原则

1. 已确认发现来自正文与证据，候选疑点和未核验内容分别说明。
2. 深度由读者与页面职责决定，审核者知道某个机制不代表页面已解释。
3. 来源路径、登记和机械检查有效，不能代替事实及引用核验。
4. 结论与实际覆盖相称，定向或抽样核验说明选择依据。
5. 修改建议保留机制、条件、反例、证据和阅读联系，修复按实际要求执行。

## 工作步骤

### 1. 确定范围与审核依据

读取用户指定范围内的正文和规范，识别页面职责、重要主张及核心解释路径。范围较大时选择与用途有关的核心页面和主张，说明覆盖方式。

从具体疑点和知识依赖定向扩展，补读直接相关的候选与来源，不默认扫描全部 raw 或把范围外内容列为已审核。

### 2. 检查机械结构

需要检查管理文件、链接、锚点或导航时，使用 [wiki-lint](../wiki-lint/SKILL.md) 的 [脚本](../wiki-lint/scripts/check_wiki.py)。从项目根目录运行：

```bash
python3 .agents/skills/wiki-lint/scripts/check_wiki.py --root .
```

局部审核可增加 `--paths` 指定相对路径，并说明工具跳过了全局导航可达性。读取 JSON 的错误、提醒和跳过项；工具未运行或失败时说明实际限制，继续可以完成的内容审核。

脚本只检查机械结构，不证明正文、来源支持、科学结论或运行结果正确。

### 3. 核验事实与关键证据

对范围内的核心结论、关键数字、公式、重要归因及比较主动回查来源。按现有引用定位实际原件，核对来源身份与版本、陈述上下文、对象、条件及支持程度。

检查是否遗漏改变含义的前提，是否把作者主张写成无条件事实、把整理者解释写成证明、把局部结果写成一般收益。公式和图表抽取不可靠时查看原始页面；代码阅读与真实运行分别说明。

来源不可得或尚未找到依据时，报告证据不足或未核验，避免直接判为已确认事实错误。来源之间存在分歧时说明发生在哪一层，保留未解决部分。

### 4. 检查解释与跨页一致性

沿实际正文和必要链接，检查读者能否理解问题、机制或步骤、前提、证据及限制。靠审核者自己的知识才能接上的部分定位为解释断点。

读取链接目标，确认其承担所需解释。已有页面能承接时建议准确连接；目标也不足时指出具体补充位置。

对跨页术语与结论先对齐定义、对象、版本和条件，再判断矛盾或合理差异。声称旧结论过时时核对新来源是否实际改变同一条件下的结论。

### 5. 判断重要知识缺口

从 Wiki 用途与读者需求提出具体缺口，说明为什么影响理解或使用。用名称、别名与机制检索并读取相关正文，确认现有承接及查找范围。

缺少链接不代表全库没有知识；查找受限时使用与范围相称的表述。建议说明需要补什么、解释到什么程度，以及由哪个现有页面承接或为什么新建。

### 6. 整理发现，按要求修复

每项发现给出实际位置、问题、证据、影响与最小建议，确认问题与待核疑点分别说明。按影响安排处理顺序，不因个人写法偏好要求全库统一。

只有审核要求时交付报告。用户已要求修复时处理范围内问题，保留用户修改及知识价值；需要重要范围或结构取舍时说明影响并与用户商量。

修复后重读受影响正文和关联来源，复跑必要机械检查，维护相关链接、INDEX 及实质变化后的 SELF。报告已修复、待修复与未核验内容，不能仅凭写入成功宣称修复完成。

按以下条件检查交付：

| 评估项 | 完成条件与依据 |
| --- | --- |
| 覆盖透明 | 实际页面、来源回查和选择方式明确，未核验部分可辨识。 |
| 发现有依据 | 已确认问题有实际正文和证据位置，证据不足与事实错误分开。 |
| 深度与关联可判断 | 核心解释路径、必要链接与分歧经过阅读，影响和承接建议具体。 |
| 修复可核对 | 建议保留知识价值，实际修复、剩余问题及复查依据明确。 |

完成审核表示约定范围的检查与报告已完成；报告中可以仍有问题。修复是否完成按实际改动与复查另行判断。

## 输出

交付实际范围与检查方式、已确认发现、待核内容、重要缺口及必要建议。已修复时提供实际位置和复查结果；没有已确认问题时说明实际检查与未覆盖范围。不默认创建审核日志或新的研究任务。

## 校验

- [ ] 适用标准与实际覆盖明确，检查结论没有扩展到未读取范围。
- [ ] 已确认发现、候选疑点与未核验内容分别说明，关键主张有真实回查。
- [ ] 读者路径与关联承接经过阅读，条件差异没有被误报为矛盾。
- [ ] 缺口判断有查找依据，合并或删除建议保留知识价值。
- [ ] 修复与用户要求一致，实际正文、来源和机械结构已经按范围复查。
